# NTE Task Tracker

「Neverness to Everness」のデイリー・ウィークリー・シーズンタスク管理ツール

## 🎮 デモ

https://kaedeno1022.github.io/nte/

## ✨ 機能

### タスク管理
- **デイリータスク管理**: 毎日のやるべきタスクをチェックリスト形式で管理
- **ウィークリータスク管理**: 週次タスクを管理
- **シーズン/隔週タスク管理**: 長期タスクを管理

### 進捗管理
- **リアルタイム進捗表示**: 各カテゴリの完了率を視覚的に表示
- **残タスク数カウント**: 残りのタスク数を常時表示

### 便利機能
- **最低限モード**: 「必須」タスクのみを表示するモード切替機能
- **タスク編集**: デフォルトタスクとカスタムタスクの両方を編集可能
- **個別リセット**: デイリー、ウィークリー、シーズンごとにリセット可能
- **全リセット**: 全てのチェック状態を一括でリセット
- **LocalStorage保存**: チェック状態を自動保存（ブラウザを閉じても保持）

### デザイン
- **レスポンシブデザイン**: PC・タブレット・モバイル対応
- **ダークテーマ**: 目に優しい暗色デザイン
- **ネオンアクセント**: サイバーパンク風のビジュアル
- **優先度の可視化**: 色分けでタスクの優先度を直感的に表示

## 🚀 使い方

### 基本操作
1. タスクの左側のチェックボックスをクリックして完了状態を管理
2. 完了したタスクは自動的に打ち消し線が表示され、透明度が下がります
3. チェック状態は自動的にブラウザに保存されます

### リセット機能
- **デイリーリセット**: デイリータスクのチェックを全て外します
- **ウィークリーリセット**: ウィークリータスクのチェックを全て外します
- **シーズンリセット**: シーズンタスクのチェックを全て外します
- **全リセット**: すべてのタスクのチェックを全て外します

### 最低限モード
「最低限モード ON」ボタンをクリックすると、「必須」カテゴリのタスクのみが表示されます。時間がない時の最低限やるべきタスクに集中できます。

### タスク編集機能
1. 各タスクの右側にある ✏️ ボタンをクリックして編集できます
2. デフォルトタスクもカスタムタスクも編集可能
3. タスク名、優先度、カテゴリ、コメントを変更できます
4. 編集されたデフォルトタスクは設定パネルから元に戻すこともできます

### カスタムタスク
1. ⚙ 設定ボタンをクリックして設定パネルを開きます
2. 「カスタムタスク」タブに切り替えます
3. フォームから独自のタスクを追加できます
4. 優先度を選択すると、自動的に適切なカテゴリに分類されます
5. 追加したタスクは削除や編集が可能です

## 🎨 優先度システム

タスクは3つの優先度レベルで色分けされています：

- 🔴 **赤 (high)**: 高優先度 - 必須タスク
- 🟡 **黄 (mid)**: 中優先度 - 余裕があれば実行
- 🔵 **青 (low)**: 低優先度 - 確認系タスク

## 🔧 開発

### ローカルでの実行

1. リポジトリをクローン
```bash
git clone <repository-url>
cd nte
```

2. ローカルサーバーで起動
```bash
# Python 3を使用する場合
python -m http.server 8000

# Node.jsのhttp-serverを使用する場合
npx http-server
```

3. ブラウザで `http://localhost:8000` にアクセス

### タスクデータのカスタマイズ

[script.js](script.js) の `DATA` オブジェクトを編集することで、タスクの追加・削除・変更が可能です：

```javascript
const DATA = {
  daily: [
    {
      category: "必須",
      tasks: [
        ["タスク名", "優先度"], // 優先度: high/mid/low
        // ...
      ]
    }
  ]
  // ...
};
```

# Focus Ops

作業記録ツール

## 機能

### 作業表ツール（work_sheet.html）

- 社員用 / BP用 のモード切り替え
- 出退勤時刻・作業内容を日別に記録
- チェックイン/チェックアウトでワンクリック記録
  - 退勤し忘れて日付が変わった場合は警告し、その日の退勤時刻を入力して登録できる
  - 誤った出社記録は取り消せる。出社時刻だけを後から修正することもできる
  - 退勤前に入力した作業内容は保存され、リロードやタブを閉じても消えない
  - 18時半以降の退勤や定時外の出退勤では、退勤前に18時以降休憩・遅刻/早退を選べる（社員用のみ）
- 振替・代休・変則勤務・有休などの勤務状態に対応（Excelマクロと同じ入力チェック）
- イベント登録（繰り返し予定の自動反映）
- 月間カレンダービュー（入力状況・作業時間を月単位で確認、日付クリックで編集/入力。日付を指定したイベントはセルに表示）
  - 今日より前の平日で未入力の日を点線枠で示し、件数を表示する（祝日は判定しないため、休みの日は「入力不要」で候補から外す）
- 月次サマリー（実総作業時間・法定時間外労働・深夜労働・各種休暇日数など、Excelマクロと同じ集計項目）
  - 集計をタブ区切りでクリップボードにコピーできる（Excelの集計欄との突き合わせ用）
  - 週ごとの労働時間・週40時間超・日8時間超の内訳を表示する（法定時間外がどの週で発生しているかの確認用）
  - 法定時間外労働が月45時間の8割（36時間）を超えたら注意、45時間を超えたら警告を表示する（上限値は `constants.js` で変更できる）
  - 有休・プロジェクト休暇の残日数表示（基準日時点の残日数を設定すると、それ以降の消化分を自動で差し引いて表示。付与日数の計算・繰越はしない）
- 作業内容の入力補助（過去の入力履歴のサジェスト・前回の内容の再利用・該当日のイベント内容の取得・文字数カウンタ）
- 入力フォームの内容をカレンダーから選んだ複数日へ一括登録
- Ctrl+Enter（Macは⌘+Enter）で登録・更新・退勤
- 登録・削除・コピー・一括処理の取り消し（トーストの「元に戻す」）
- データの一括削除は月単位のみ（全期間の一括削除は用意しない。削除前に件数と日付範囲を確認する）
- JSON エクスポート / インポート（インポートは対象月のみを差し替え。取り込む前に月ごとの件数を確認し、日付の形式が不正な行・重複した日付は除外する）
- 全体バックアップ / 復元（社員用・BP用の勤務データ、イベント、15分調整差分、休暇残日数の基準値をまとめて1ファイルに出力。復元は全データの置き換えで、置き換え前の状態を自動でダウンロードする）
- 一定期間全体バックアップを取っていない場合のバックアップ案内
- 複数タブで開いている場合、別タブでの変更を自動で読み込む（編集中のモーダルは閉じる）
- 保存データが壊れて読めない場合は、元の文字列を `<キー>_corrupt_<日時>` に退避してから続行する（退避できない場合は上書きを止める）
- ダークモード対応

### 共通

- レスポンシブ対応（PC / タブレット / モバイル）
- 日時はすべて日本時間（JST）で扱う（端末のタイムゾーンに依存しない）
- アクセス解析なし。記録したデータは外部へ送信せず、ブラウザの LocalStorage にのみ保存する
- 外部リソースの読み込みは一切なし。完全にオフラインで動く

---

## 技術スタック

- HTML5 / CSS3 / JavaScript (ES6+)
- フレームワーク・ビルドツールなし（バニラ JS）
- データ保存: LocalStorage のみ（サーバーなし）

## ファイル構成

```
focus-ops/
├── index.html              # ランディングページ
├── work_sheet.html         # 作業表ツール
├── css/
│   ├── variables.css       # CSS変数・カラーパレット（ダークモード含む）
│   ├── index.css           # ランディング専用
│   └── worksheet.css       # 作業表専用（独立したCSS変数体系）
├── js/
│   ├── theme.js            # ダークモード管理
│   └── workSheets/         # 作業表ツール専用モジュール
│       ├── constants.js    # 定数・LocalStorageキー
│       ├── state.js        # モジュールスコープの状態と setter
│       ├── utils.js        # 日付・時刻ユーティリティ（JST統一）
│       ├── calc.js         # 勤怠計算（Excelマクロの集計仕様に準拠）
│       ├── storage.js      # LocalStorage読み書き（例外処理を集約）
│       ├── ui.js           # トースト・確認ダイアログ・モーダル・タブ
│       ├── calendar.js     # 月間カレンダービュー・日付選択カレンダー
│       ├── forms.js        # フォーム制御・入力補助
│       ├── render.js       # 一覧描画・月次サマリー・バックアップ案内
│       ├── data.js         # データCRUD・取り消し・時間フォーマット整理
│       ├── events.js       # イベントデータ管理
│       ├── checkin.js      # 出社・退勤の記録
│       ├── json.js         # JSON入出力・月単位マージ・全体バックアップ
│       ├── copy.js         # 他の日付へのコピー
│       └── main.js         # 初期化・モード切り替え・window公開
└── tests/                  # Node標準テストランナー用テスト
    ├── helpers/load.js
    ├── calc.test.js        # 日次の作業時間計算
    ├── summary.test.js     # 月次集計・週別内訳・時間外労働の上限警告・入力漏れの候補
    ├── validate.test.js    # 入力チェック
    ├── utils.test.js       # 日付・時刻ユーティリティ（JST統一の検証を含む）
    ├── json.test.js        # JSONインポート時の月単位マージ・取り込み対象の選り分け・バックアップ形式の検証
    └── storage.test.js     # 壊れた保存データの退避
```

## ローカル起動

```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server
```

`http://localhost:8000` をブラウザで開く。

---

## テスト

勤怠計算・ユーティリティ・JSONマージのロジックを Node の標準テストランナーで検証する（追加パッケージ不要）。

```bash
node --test tests/*.test.js
```

DOM を伴う挙動（描画・モーダル・チェックイン操作）はテスト対象外なので、ブラウザで確認する。

### WSL 環境での設定

```bash
git config core.filemode false
```

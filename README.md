# Focus Ops

業務タスク管理と作業記録の統合ツール

## ✨ 機能

### デイリータスク管理（daily.html）
- **デイリー/ウィークリー/シーズンタスク**: チェックリスト形式で管理
- **リアルタイム進捗表示**: 各カテゴリの完了率を視覚的に表示
- **残タスク数カウント**: 残りのタスク数を常時表示
- **最低限モード**: 「優先度：高」タスクのみ表示するモード切替
- **タスク編集**: デフォルトタスク・カスタムタスクの両方を編集可能
- **個別/全リセット**: デイリー・ウィークリー・シーズンごとにリセット可能
- **プロジェクト・タグ・締め切り管理**: タスクへのメタデータ付与
- **LocalStorage保存**: チェック状態を自動保存

### 作業表ツール（work_sheet.html）
- **出退勤時刻の記録**: 出勤・退勤時刻を日ごとに記録
- **作業内容の記録**: 日別の作業内容を詳細に管理
- **簡易チェックイン/チェックアウト**: ワンクリックで出退勤を記録
- **振替・代休・変則勤務対応**: 各種勤務形態に対応
- **JSON入出力**: データのエクスポート/インポート対応
- **クリップボードコピー**: 作業内容を書式付きでコピー

### 共通
- **レスポンシブデザイン**: PC・タブレット・モバイル対応
- **Cookie同意/プライバシーポリシー**: GA4計測に対応

## 🚀 使い方

### デイリータスク管理
1. `daily.html` を開く
2. タスクのチェックボックスをクリックして完了状態を管理
3. ⚙ 設定ボタンからカスタムタスクの追加・編集が可能
4. 各タスクの ✏️ ボタンでタスク名・優先度・プロジェクト・タグ等を編集

### 作業表ツール
1. `work_sheet.html` を開く
2. 「出勤」ボタンで出勤時刻を記録、「退勤」で退勤時刻を記録
3. 日ごとの作業内容を入力・保存
4. JSON出力でデータをバックアップ/移行可能

## 🛠️ 技術スタック

- **HTML5**: セマンティックHTML、ARIA属性によるアクセシビリティ対応
- **CSS3**: CSS Variables、Grid、Flexbox、レスポンシブデザイン
- **JavaScript (ES6+)**:
  - Vanilla JavaScript（フレームワーク不使用）
  - ES6モジュール（workSheet/）とスクリプト分割（daily）の混在構成
  - LocalStorage API
  - イベント駆動アーキテクチャ

## 🎨 優先度システム（デイリータスク）

- 🔴 **赤 (high)**: 高優先度タスク
- 🟡 **黄 (mid)**: 中優先度 - 余裕があれば実行
- 🔵 **青 (low)**: 低優先度 - 確認系タスク

## 🔧 開発

### ローカルでの実行

```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server
```

ブラウザで `http://localhost:8000` にアクセス。

### Cygwin/WSL環境での設定

ファイルモードの差分誤検知を防ぐ：

```bash
git config core.filemode false
```

# Focus Ops

作業記録ツール

## 機能

### 作業表ツール（work_sheet.html）

- 社員用 / BP用 のモード切り替え
- 出退勤時刻・作業内容を日別に記録
- チェックイン/チェックアウトでワンクリック記録
  - 退勤し忘れて日付が変わった場合は警告し、その日の退勤時刻を入力して登録できる
  - 誤った出社記録は取り消せる
- 振替・代休・変則勤務・有休などの勤務状態に対応（Excelマクロと同じ入力チェック）
- イベント登録（繰り返し予定の自動反映）
- 月間カレンダービュー（入力状況・作業時間を月単位で確認、日付クリックで編集/入力）
- 月次サマリー（実総作業時間・法定時間外労働・深夜労働・各種休暇日数など、Excelマクロと同じ集計項目）
  - 集計をタブ区切りでクリップボードにコピーできる（Excelの集計欄との突き合わせ用）
- 作業内容の入力補助（過去の入力履歴のサジェスト・前回の内容の再利用・文字数カウンタ）
- 登録・削除・コピー・一括処理の取り消し（トーストの「元に戻す」）
- JSON エクスポート / インポート（インポートは対象月のみを差し替え）
- Excel（.xlsm）書込（作業確認表シートへの直接書き込み、VBAマクロは保持したまま出力）
- 一定期間エクスポートしていない場合のバックアップ案内
- ダークモード対応

### 共通

- レスポンシブ対応（PC / タブレット / モバイル）
- 日時はすべて日本時間（JST）で扱う（端末のタイムゾーンに依存しない）
- アクセス解析なし。記録したデータは外部へ送信せず、ブラウザの LocalStorage にのみ保存する
- 唯一の外部リソースは Excel書込で使う JSZip（CDN）で、その機能を使うときだけ読み込む

---

## 技術スタック

- HTML5 / CSS3 / JavaScript (ES6+)
- フレームワーク・ビルドツールなし（バニラ JS）
- データ保存: LocalStorage のみ（サーバーなし）
- Excel書込のみ JSZip 3.10.1 を CDN から動的に読み込む（他の機能はオフラインで動く）

## ファイル構成

```
focus-ops/
├── index.html              # ランディングページ
├── work_sheet.html         # 作業表ツール
├── css/
│   ├── variables.css       # CSS変数・カラーパレット（ダークモード含む）
│   ├── index.css           # ランディング専用
│   └── worksheet.css       # 作業表専用（独立したCSS変数体系）
├── js/
│   ├── theme.js            # ダークモード管理
│   └── workSheets/         # 作業表ツール専用モジュール
│       ├── constants.js    # 定数・LocalStorageキー
│       ├── state.js        # モジュールスコープの状態と setter
│       ├── utils.js        # 日付・時刻ユーティリティ（JST統一）
│       ├── calc.js         # 勤怠計算（Excelマクロの集計仕様に準拠）
│       ├── storage.js      # LocalStorage読み書き（例外処理を集約）
│       ├── ui.js           # トースト・確認ダイアログ・モーダル・タブ
│       ├── calendar.js     # 月間カレンダービュー・日付選択カレンダー
│       ├── forms.js        # フォーム制御・入力補助
│       ├── render.js       # 一覧描画・月次サマリー・バックアップ案内
│       ├── data.js         # データCRUD・取り消し・時間フォーマット整理
│       ├── events.js       # イベントデータ管理
│       ├── checkin.js      # 出社・退勤の記録
│       ├── json.js         # JSON入出力・月単位マージ
│       ├── excelImport.js  # Excel(.xlsm)作業確認表への直接書き込み
│       ├── copy.js         # 他の日付へのコピー
│       └── main.js         # 初期化・モード切り替え・window公開
└── tests/                  # Node標準テストランナー用テスト
    ├── helpers/load.js
    ├── calc.test.js        # 日次の作業時間計算
    ├── summary.test.js     # 月次集計
    ├── validate.test.js    # 入力チェック
    ├── utils.test.js       # 日付・時刻ユーティリティ（JST統一の検証を含む）
    └── json.test.js        # JSONインポート時の月単位マージ
```

## ローカル起動

```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server
```

`http://localhost:8000` をブラウザで開く。

---

## テスト

勤怠計算・ユーティリティ・JSONマージのロジックを Node の標準テストランナーで検証する（追加パッケージ不要）。

```bash
node --test tests/*.test.js
```

DOM を伴う挙動（描画・モーダル・チェックイン操作）はテスト対象外なので、ブラウザで確認する。

### WSL 環境での設定

```bash
git config core.filemode false
```
